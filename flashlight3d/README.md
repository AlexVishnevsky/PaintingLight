# Flashlight 3D

Android-застосунок: PBR-ліхтарик, жорстко закріплений до екрана, у якому
відбиття оточення рухаються разом із нахилом телефона.

Що вже є:

- рендер на [Filament](https://github.com/google/filament) (Kotlin, без ARCore);
- трекінг голови через фронтальну камеру (CameraX + ML Kit) і off-axis
  проєкція: екран працює як вікно, ліхтарик лінзою торкається скла, а хвіст
  іде в глибину й «гуляє» при русі голови;
- якщо обличчя зникло з кадру, паралакс продовжується від гіроскопа з тієї
  позиції, де обличчя було втрачено;
- жива cubemap: кадри фронталки розкладаються по сфері за орієнтацією
  телефона (гіроскоп) і відбиваються в металі; без дозволу на камеру
  лишається процедурна «фотостудія»;
- чистий чорний фон (AMOLED), ліхтарик займає 85% висоти екрана;
- тап по ліхтарику вмикає справжній LED телефона і світіння лінзи.

Налаштування й діагностика:

- шестерня у правому верхньому куті відкриває панель з усіма параметрами
  (розмір і нахил ліхтарика, сила й знак паралаксу, згладжування, яскравість
  і дзеркалення cubemap, bloom тощо); значення зберігаються;
- якщо запуск обірвався, наступного разу застосунок показує звіт (стадія
  запуску, виняток, logcat), який можна скопіювати чи надіслати, і пропонує
  режим сумісності: 1 — без камери, 2 — драйвер Vulkan замість OpenGL,
  3 — мінімальний рендер без пост-обробки.

Далі за планом: окрема кнопка з червоного пластику зі свайпом, ARCore для
паралаксу cubemap, фон із задньої камери.

## Як отримати APK без ПК

Кожен push у `flashlight3d/` збирає APK у GitHub Actions і оновлює реліз
`flashlight3d-latest`. Відкрий на телефоні сторінку Releases репозиторію,
завантаж `flashlight3d.apk` і встанови (потрібен дозвіл на встановлення з
браузера). Збірки підписані одним ключем, тож нова ставиться поверх старої.

## Локальна збірка

```
./gradlew assembleDebug
```
