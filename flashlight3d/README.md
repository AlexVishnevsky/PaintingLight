# Flashlight 3D

Android-застосунок: PBR-ліхтарик, жорстко закріплений до екрана, у якому
відбиття оточення рухаються разом із нахилом телефона.

Що вже є:

- рендер на [Filament](https://github.com/google/filament) (Kotlin, без ARCore);
- процедурне HDR-оточення «фотостудія», яке генерується на старті;
- оточення прив'язане до світу через гіроскоп, ліхтарик — до екрана;
- перетягування пальцем крутить і нахиляє ліхтарик;
- тап вмикає справжній LED телефона і світіння лінзи.

Далі за планом: трекінг голови й off-axis проєкція, cubemap із камер,
ARCore для паралаксу, фон із задньої камери.

## Як отримати APK без ПК

Кожен push у `flashlight3d/` збирає APK у GitHub Actions і оновлює реліз
`flashlight3d-latest`. Відкрий на телефоні сторінку Releases репозиторію,
завантаж `flashlight3d.apk` і встанови (потрібен дозвіл на встановлення з
браузера). Збірки підписані одним ключем, тож нова ставиться поверх старої.

## Локальна збірка

```
./gradlew assembleDebug
```
